# 223 — M31 메모리 최적화 P1 GPIO 상태 절감

## 1. 판정

2026-09-22 P1의 첫 고정 저장소 right-size로 논리 핀마다 중복 보존하던
`IoResourceLease`를 `PinRuntimeState`에서 제거했다. 소유권 commit 뒤의 정상 상태는 이미 중앙
`IoResourceTable`이 owner와 generation을 보존한다. 16-entry rollback snapshot은 reserve부터
commit/rollback까지의 transaction 지역 변수와 peripheral handover 객체에만 유지한다.

공개 API, canonical pin/alias mapping, ownership generation, rollback과 peripheral handover 계약은
바꾸지 않았다. 물리 장치에는 접근하지 않았고 P1 전체 완료 판정은 아니다.

## 2. 정적 RAM 전후 비교

동일 `p0_serial_spi` adaptive clean image와 NCS v3.4.0, toolchain `dcbdc366a1` 조건의
`.data + .bss`를 비교했다.

| 항목 | P0 기준 | P1 변경 | 절감 |
| --- | ---: | ---: | ---: |
| 전체 정적 RAM | 50,877 B | 25,405 B | 25,472 B |
| `pin_runtime_states` | 25,856 B | 384 B | 25,472 B |
| RAM 사용률 | 19.4080% | 9.6912% | 9.7168%p |
| RAM headroom | 211,267 B | 236,739 B | +25,472 B |

새 image의 금지 symbol은 0건이고 75/85% budget gate는 PASS다. 역할 선언이 없는 Core
SPI 예제에도 이 개선이 퇴행하지 않도록 `ADAPTIVE_CORE_RAM_CEILINGS`의
`p0_serial_spi` 상한을 27,000 B로 고정했다.

충돌, committed handover 복구, 두 핀 nested handover와 free-pin release 계약을 포함한다.

## 4. 다음 작업

다음 P1 후보는 부팅 고정 UART20의 792-byte 전역 lease다. 초기 등록 transaction이 끝난 뒤
소유권은 중앙 table에 남으므로, 실패 unwind를 보존한 지역 lease로 바꿀 수 있는지 같은 방식으로
Host/target 계약과 fresh ELF delta를 확인한다. 이후 SPI runtime route 4,224 B와 역할별 GATT
queue/state를 순서대로 감사한다.
