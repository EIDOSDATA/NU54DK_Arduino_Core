## macOS 27 검증

macOS 27.2.1(26B131) Apple Silicon에서 격리한 Arduino CLI 1.5.1과 NCS 3.4.0(`ccc010f809`)을 사용했습니다.

- C12 `0.6.0-rc.1`을 `0.6.0`으로 갱신하고, 동일 버전 재설치 요청과 제거 후 재설치를 확인했습니다. 패키지 파일 960개를 ZIP과 대조하고 예제 204개를 찾았습니다. 사용자 데이터와 SDK가 보존됐습니다.
- 설치본에서 Blink와 BoardInfo를 컴파일했습니다. Blink의 BIN과 HEX는 [C12에서 실제 업로드한 이미지](<338_HOST_W07_macOS_27_Arduino_IDE_Upload_교정.md>)와 바이트 단위로 일치했습니다. BoardInfo의 ELF에 `0.6.0` 문자열이 들어 있습니다.
- 기록 SHA-256은 설치 수명주기 `3b7519d9750288e29d8ca63522bbe50088c7f8f41e474cbd7c42b89903734e76`, 컴파일 비교 `3d79c269e0783642f70ef714d7ac92b462c45ba325dfaeb141bf28d907d82c9c`입니다. 이번 변경 검증에서 하드웨어 작업은 0건입니다.


Mac에서 M33 원장의 전체 catalog 검사에 순서 차이가 있었습니다. C12에서도 같은 오류를 재현했습니다. 두 결과를 예제 경로순으로 대조해 204개 행의 내용이 일치함을 확인했습니다.

## CI와 남은 심사

첫 후보의 Windows Host 단위 검사에서는 M28이 과거 제품 버전 `0.5.0`을 현행 소스에서 요구해 실패했습니다. 과거 버전은 공개 v0.5.0의 고정 커밋에서 확인하도록 검사만 수정했고, 현행 소스 버전 검사는 R05가 담당합니다. [원본 실패 로그](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/45227389510/job/137877435236)

수정 후보의 Windows Host 단위 검사와 선행 작업 8개가 통과했고, 마지막 대표 구성 빌드는 이 기록 작성 시점에 진행 중이었습니다. [현재 후보 M12](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/45229102236)

[Native 스모크와 이미지 비교](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/45227270584), [W06 빌드 전용 CI](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/45227270853)
