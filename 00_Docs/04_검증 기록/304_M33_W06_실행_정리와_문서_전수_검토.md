## 6. 자료 정리의 한계

문서 작업 직전 공간 정리에서는 e2/e4/e7/e10의 원본 ZIP과 전 파일 byte를 대조한 중복 extraction,
e2~e10의 source/submodule/clean/활성 참조를 검사한 독립 Arduino clone만 제거했다.
receipt는 `D:\w06\archive`에 있으며 ZIP과 기록·실패 진단은 남아 있다. Git clone은 exact commit으로,
extraction은 검증한 ZIP으로 재생성할 수 있다. 제거한 옛 경로를 바로 실행하지 않는다.

사용자는 후속 artifact ZIP 삭제를 취소했다. 이번 문서 정비에서 ZIP·raw·runtime·실패 원본은 삭제하지 않았다.
GitHub의 `expired=false`는 영구 백업이 아니며 이력 bundle의 옛 C 경로도 현재 존재 보장이 아니다.
