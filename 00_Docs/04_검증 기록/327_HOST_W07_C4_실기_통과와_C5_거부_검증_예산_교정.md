C5는 검증기 두 곳의 유한 timeout과 경계 회귀만 교정한다. C4 대비 cores·libraries·templates·
tests/hil의 firmware 입력은 바꾸지 않는다. 보안 수준·SDK pin·profile 거부 조건·재시도 횟수를
변경하지 않는다. 예상 marker 없이 단순 nonzero exit만 나온 경우와 성공 exit·성공 ELF가 있는
경우는 계속 FAIL이다. C4 native의 모든 worker를 다른 run/attempt와 합성하지 않으며 새 exact
C5 실행의 원형으로 최종 판정한다.
