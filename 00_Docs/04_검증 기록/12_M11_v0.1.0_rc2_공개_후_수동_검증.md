# M11 v0.1.0-rc.2 공개 후 수동 검증 기록

| 항목 | 내용 |
| --- | --- |
| 문서 상태 | **완료** — 공개 RC2의 clean Windows 설치·compile·실제 보드 upload·실행 수동 검증 통과 |
| 검증일 | 2026-08-28 |
| 검증자 | Quantum / NUCODE |
| 대상 패키지 | `nucode:zephyr@0.1.0-rc.2` |
| 대상 보드 | NU54DK / `nucode:zephyr:nu54dk` |
| Arduino IDE | 2.3.10 |
| 다음 정식 버전 | `v0.1.0` |

## 1. 목적

이 문서는 `v0.1.0-rc.2` 공개 후 프로젝트 소유자가 별도 clean Windows PC와 실제 NU54DK로
수행한 최종 수동 검증을 기록한다. rc.1의 exact 자동 gate 증거와 rc.2 공개 전 자동 gate는
그대로 보존하며, 수동 확인 결과를 자동 생성된 evidence manifest로 소급 표현하지 않는다.

## 2. 검증 결과

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 공개 Boards Manager 패키지 설치 | **PASS** | clean Windows의 Arduino IDE 2.3.10에서 `0.1.0-rc.2` 설치 확인 |
| Core와 보드 열거·선택 | **PASS** | `NUCODE NU54DK Zephyr Boards`, `NU54DK (nRF54L15, Zephyr)` 확인 |
| Sketch compile | **PASS** | FLASH 55,216 byte(3%), RAM 16,301 byte(6%)로 완료 |
| 실제 NU54DK upload | **PASS** | 프로젝트 소유자가 clean Windows에서 실제 보드 업로드 성공 확인 |
| 업로드 후 실행 | **PASS** | 프로젝트 소유자가 실제 보드의 정상 실행 확인 |

Arduino IDE 화면은 패키지 설치·보드 선택·compile 결과와 메모리 사용량을 직접 보여 준다.
실제 NU54DK upload·실행과 clean Windows 여부는 프로젝트 소유자의 수동 확인을 근거로 한다.

## 3. 자동 검증과의 경계

- rc.2 공개 artifact의 package integrity, host, Arduino fixed-package, Zephyr와 문서 자동 gate는
  **5/5 PASS**다.
- rc.1 exact artifact의 필수 gate **8/8 PASS**는
  [역사적 M11 기준선](11_M11_v0.1.0_rc1_릴리스_후보_기준선.md)에만 귀속한다.
- rc.2 공개 시점에 생성하지 않은 strict M11 evidence manifest를 이 수동 검증으로 대신하거나
  새 자동 gate **8/8 PASS**로 기록하지 않는다.
- firmware runtime, NU54DK DTS, pin mapping과 Upload 구현은 rc.1 대비 변경되지 않았다.

## 4. 판정

공개 `v0.1.0-rc.2`는 clean Windows의 Arduino IDE 2.3.10 설치·compile과 실제 NU54DK
upload·실행까지 수동 검증을 통과했다. rc.1에서 발견한 설치 완료 출력 인코딩 결함이
교정됐고 공개 후보의 사용 경로에서 추가 blocker가 발견되지 않았으므로 **M11을 완료**로
판정한다.

다음 정식 버전은 **`v0.1.0`**으로 확정했다. 후속 정식판은 별도 stable package·index·tag와
GitHub Release로 공개하며, 이 RC2 수동 기록을 stable exact HIL 증거로 바꾸지 않는다.
