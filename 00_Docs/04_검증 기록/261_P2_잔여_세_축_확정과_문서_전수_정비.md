## 다시 필수 gate로 넣지 않는 항목

- **NCS v3.4.0 고정:** P2 완료를 위해 SDK/controller를 변경하지 않는다.
- **제품 SDC DF IQ RX:** 고정 nRF54L15 지원 범위 밖인 `UNSUPPORTED`이며 P2에서 제외한다.
  DF AoA 송신 결과와 분리한다. Zephyr LL의 연결형 내부 진단·connectionless 실패는
  과거 실험 증거로 보존하며 제품 RX 지원이나 필수 재실행으로 승격하지 않는다.
  근거는 [259번 지원 경계](259_M31_P2_DF_고정_SDK_지원_경계.md)다.
- **CS 간헐 RF/controller loss·counter gap:** 비차단 관찰값이다. 0-gap이나 모든 누락의
  원인 규명을 P2 완료 조건으로 요구하지 않는다. 유효 raw·step·종료·fault와
  중복/역행 counter 검사는 유지한다. [260번 결과](260_M31_P2_CS_누락_분류와_256_step_장시간.md)를 따른다.
- **SDC 내부 high-water:** 현재 노출되지 않는다는 사실을 기록하되 별도 필수 gate로
  만들지 않는다. SDK 요구 크기와 정렬 확인은 내부 최고치 관측이나 축소 허가가 아니다.
- 명시한 지원 용량·안전 여유를 확인하는 데 필요한 조건을 선택한다. 모든 전원 차단·
  다중 링크·전체 조합을 일괄 추가하거나, W04/W05 전체 기능 마감을 P2에 합치지 않는다.

M31 전체는 W01~W03 **3/8**, W03 Audio **11/11**을 유지한다. W04/W05 마감과
W06~W08, Windows v0.5.0 패키지·공개 gate는 P2와 별도다. 현재 설치·지원 버전은
v0.4.1 하나이며 HOST-W04~W08은 사용자 보류, M32/M33은 후속 제품선이다.

## 전수 검토 방법과 정리 내용

시작 시 본 저장소 Markdown 416개와 board submodule 6개를 열거했다.
본 저장소 416개 중 415개는 자체 문서·고지이고 1개는 vendored ArduinoCore-API 원본이다.
이 기록을 추가한 최종 대상은 **본 저장소 417개 + board 6개 = 423개**다.
`.rst` 문서는 없고 `.txt` 244개는 증거 148개·빌드 입력 92개·설정 입력 4개다.
board submodule의 회로도 PDF 1개는 외부 하드웨어 원본으로 보존하며 이번 문서 본문
정비나 회로 검증 대상으로 삼지 않았다.

전체 Markdown의 inventory·UTF-8·로컬 링크·정규화 hash·동일 본문 중복과 현행 상태
키워드를 검사하고, 영향을 받는 현행 계약·인계·후속 TODO 및 관련 검증 기록을 의미 검토했다.
이것은 모든 과거 문장을 줄마다 다시 판정하거나, 과거 기능·외부 웹 링크·HIL을 전부
재검증한 감사가 아니다. 파일별 분류·처리·UTF-8/LF 정규화 SHA-256은
[문서 감사 원장](../document-review.json)에 기록한다.

현행 HANDOFF·TODO의 긴 반복 경과를 요약하고 상세 수치·실행 조건은 해당 원본 기록으로
연결했다. 오래된 DF RX·SDC 내부 계측 차단 설명을 현행 세 축과 구분하고, 과거 기록에는
현행 판정 안내를 추가했다. 역사 파일·실패 원본·공개 자산을 삭제하거나 당시 PASS/FAIL을
새 결과로 덮어쓰지 않았다. 동일 본문의 중복 파일은 발견하지 않아 문단만 정리했다.
기존 감사 JSON의 오래된 현재 상태·누적 이력 복사는 이번 snapshot으로 교체하고, 이전
원장은 시작 commit의 같은 파일을 통해 추적한다.
