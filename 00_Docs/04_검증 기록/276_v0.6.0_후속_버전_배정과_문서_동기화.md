## 결정과 범위

2026-09-28 프로젝트 소유자는 M32·M33을 v0.6.0으로 배정하는 제안에 동의하고 후속 개발 관련
모든 문서를 수정하도록 요청했다. 제안에 포함된 뒤 제품선도 순차 이동하되 M 번호와 기능
범위·기존 검증 조건은 유지한다.

| 대상 | 종전 계획 | 새 계획 |
| --- | --- | --- |
| M32·M33 | 후속 버전 미정 | **v0.6.0** |
| M34~M37 | v0.6.0 Security/Update | **v0.7.0** |
| M38~M41 | v0.7.0 Radio/Network | **v0.8.0** |
| M42~M45 | v0.8.0 Matter | **v0.9.0** |

이 기록은 버전 배정과 문서 변경의 증거다. 기능 구현·실물 시험·Host 재개나 공개 승인이 아니다.
M32 0/12, M33 0/8과 HOST 3/8·W04~W08 사용자 보류는 유지한다. 별도 ARF 배포 버전은 이번
배정에 자동 포함하지 않는다. v0.5.x는 유지보수용이며 새 수정판을 만들지 않았다.

## 기준선과 보존

- 시작 source는 `4790e3fa532ffea00bfd96780079cbadea263ca5`, 작업 트리는 깨끗했다.
- 시작 checkout은 `Release-0.5.0`이었다. 같은 SHA의 `main`으로 이동해 후속 문서를 수정하며
  `Release-0.5.0` 백업 ref는 움직이지 않는다.
- 이전 문서 마감 source의 [M12 실행](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/36316010285)은
  **9/9 job 성공**이며 6개 Feature set 대표 build도 실제 실행·성공했다. 이는 그 source의
  결과이며 이번 변경이나 미래 v0.6.0의 CI·기능 PASS로 재사용하지 않는다.
- 현재 stable·설치 버전, runtime 제품 문자열, package index와 공개 tag·Release·자산은 v0.5.0을 유지한다.
- 과거 문서의 당시 버전 계획·source·수치·PASS/FAIL/HOLD/NOT RUN과 원시 evidence는 보존한다.

## 문서 반영과 검증

[v0.6.0 계획](../TODO_v0.6.0.md)을 새 진입점으로 만들고 M32/M33 TODO, 전체 로드맵,
기능·예제·Host·패키징 계약과 README·HANDOFF·작업 지침의 현행 후속 안내를 동기화한다.
역사 기록에는 새 결정으로 이동하는 안내만 필요한 곳에 추가하며 과거 계획을 소급 수정하지 않는다.
문서 경로와 마일스톤 ID는 기존 인용과 증거 연결을 위해 유지한다.

최종 변경 목록·정규화 hash와 문서/생성 계약 검사 결과는
[문서 감사 원장](../document-review.json)에 기록한다. 이번 작업은 문서만 변경하며 새 보드 접속,
flash·unlock·recover·mass erase·배선 변경은 수행하지 않는다.

`v0.5.0-release-readiness.json`에서는 `deferred_scope.m32/m33`의 설명만 새 계획과 맞췄다.
릴리스의 version·source·공개 상태·gate·evidence는 변경하지 않았다. 변경 없는 역사/외부 문서는
4790e3fa의 전수 검토 결과를 상속하며 이번에 모든 기술 주장을 새로 재검증했다고 표시하지 않는다.
