# T22 전 QDEC20/21 지원 범위 재확정

2026-09-11 KST, 프로젝트 소유자는 T22 최종 승인 전에 QDEC20/21을 v0.4.0 공개 지원 범위로
전환하기로 결정했습니다. 이 기록은 지원 계약 변경과 그 영향 검증을 추적하며, 과거 물리시험
원본을 소급 변경하지 않습니다.

## 의도한 변경 범위

- `streamFabric().qdec(20U)`와 `streamFabric().qdec(21U)`를 `fabric` profile의 공개 지원
  capability로 선언합니다.
- 기본 정·역회전, debounce와 SAMPLE/REPORT event 누산의 기존 물리 근거를 지원 근거로
  사용합니다.
- 동작 중 반복 manual `read()/clear`에서 간헐적으로 재현된 `399/400`은 알려진 제한으로
  유지하고 이 경로의 무손실 누산을 보증하지 않습니다.
- 반복 Serial personality handover, 모든 주변장치 동시 조합, 정밀 ADC 정확도·clock jitter·
  음질·신호 무결성은 계속 보증 범위 밖입니다.
- 과거 QDEC 기능 240조건 FAIL·T13 QDEC 단독/C07 미실행을 PASS로 바꾸지 않습니다.

## 다시 확인할 gate

1. manifest와 생성 inventory, 설치 capability, API Doxygen 및 사용자 문서의 계약 일치
2. QDEC Host/target 계약과 `fabric` profile을 포함한 전체 영향 software gate
3. 변경된 source의 target build와 RC/stable package 재현성
4. 격리 설치·설치 예제 clean build와 대표 Upload를 포함한 T20~T21 영향 범위
5. 새 exact commit·stable plan·archive hash 제시 후 별도 T22 공개 승인

## 1차 반영과 영향 검사

QDEC20/21을 manifest `public`, route `verified`, 설치 capability `supported`로 바꾸고
`StreamFabric` API 주석·`FabricCapabilities` 예제·stable/RC 사용자 문서를 같은 제한 문구로
맞췄습니다. HIL 상태는 실제 결과대로 `partial`, concurrent HIL은 `not_run`을 유지했습니다.

`550bf30146db3c6cedc22f2212b9ee541d6c21ebb992b2cff9df98e2ae0b6102`,

`4d04cb4e7c879d94214f022a13bc376d37f737262d5aa1e0b40cb0a06553bfa3`입니다.

전체 Host 재실행은 QDEC 관련 계약을 포함한 앞선 묶음을 통과한 뒤 BLE Security native 실행
파일에서 Windows Smart App Control `WinError 4551`로 중단했습니다. Code Integrity event 3077은
해당 임시 PE가 Enterprise signing level을 충족하지 않았다고 기록했으며, assertion 또는 QDEC
source 실패가 아닙니다. 이 로컬 실패를 PASS로 바꾸지 않고, 커밋 후 원격 CI의 전체 Host 결과를
별도로 확인합니다.

현재 상태는 **지원 계약 반영 완료·T19~T21 영향 재검증 진행 중**입니다. 위 검사가 끝나기
전에는 이전 stable plan이나 archive hash를 새 T22 승인 대상으로 사용하지 않습니다.
