# 150 — v0.5.0 다중 Host 지원 계획 정비

## 1. 범위

2026-09-14에 `v0.5.0`부터 지원할 Arduino 사용자 Host 범위와 M30~M33의 구현·검증 순서를
문서화했다. 이번 변경은 계획·계약 정비이며 Linux/macOS 구현, target build 또는 실제 NU54DK
Host HIL을 수행한 결과가 아니다.

## 2. 승인한 결정

| 항목 | 결정 |
| --- | --- |
| Windows | Windows 10/11 x64 유지 |
| Linux | Ubuntu 24.04부터 당시 최신 지원 release까지, AMD64 native |
| macOS | macOS 26부터 당시 최신 지원 major까지, Apple Silicon ARM64 native |
| 시작 | M30-W01과 동시에 HOST-W01 착수 |
| 종료 | M33 `v0.5.0` 공개 전 HOST-W01~W08과 지원 matrix 완료 |
| 미래 OS | 자동 PASS 금지; candidate → 실제 Host 검증 → supported |
| 과거 버전 | `v0.4.1` 이하 Windows 전용 판정과 원본 문서·증거 보존 |

Linux ARM64·다른 Linux 배포판, Intel Mac·Rosetta, Windows on ARM, WSL/container USB upload는
현재 지원 목표에서 제외했다. Linux BLE peer나 Linux container target build는 Arduino Linux
Host PASS와 구분한다.

## 4. 후속 실행 조건

다음 구현은 M30에서 HOST-W01 Windows 전용 가정 inventory부터 시작한다. `.exe`, batch,
`%LOCALAPPDATA%`, prerequisite URL과 upload 경로를 공통 Python backend·OS descriptor로 분리하고
M30에 추가할 DFU 경로에도 같은 규칙을 적용한다.

M31은 prerequisite·build/cache·package와 세 Host CI, M32는 실제 NU54DK upload/debug/serial과
설치 lifecycle, M33은 전체 예제·지원표·release 문서를 마감한다. 각 단계에서 정적 source, Host
unit, target build, 실제 HIL을 분리하며 실행하지 않은 필수 행은 `NOT RUN`으로 유지한다.
