### P41-03 진행

로컬 `contract`, `docs`, `inventory`, `package` gate는 PASS했다. 설치기 회귀 7건도 변경 직후
PASS했다. 이후 같은 Windows에서 동적으로 생성한 시험 EXE가 애플리케이션 제어 정책에
`WinError 4551`로 간헐 차단되는 환경 사건을 확인했다. 실패한 binary는 새 process에서 동일
시험 재실행 시 PASS했으며 제품 assertion 실패가 아니다. 로컬 정책을 완화하거나 시험 실패를
숨기지 않고, 격리 GitHub Windows/Linux runner에서 수행하는 exact source CI를 최종 판정으로
사용한다.

Package·공개·설치 PASS는 아직 기록하지 않는다.

첫 비공개 `prepare`는 자산 생성 전에 릴리스 도구가 정상 submodule status의 선행 공백을
제거해 clean gitlink를 거부한 문제를 발견했다. Git 출력의 후행 개행만 제거하도록 교정하고
선행 공백 보존 회귀를 추가했다. 이 실행은 package 실패나 공개 변경이 아니다.
