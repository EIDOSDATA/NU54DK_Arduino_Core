## 완료 상태와 남은 경계

S의 요청 범위는 **56 PASS + System OFF 추가 결합 제외 2 / 58**, 범위 종료율 100%다.
이는 58/58 실기 PASS나 v0.4.0 전체 완료율이 아니다. U 준비는 100%, U 실기는 NOT RUN이다.
정확한 image·Host·CI·마지막 GPIO 정리 근거는 [113번](113_T13_S_범위_종료와_U_준비.md)에 있다.

S 정상 36조건에는 대표 C05 3600초 soak가 포함된다. 이미 끝난 시험을 남은 일정에 다시 넣지
않는다. QDEC 추가 진단과 Serial handover 제외도 유지한다. 기존 M15의 GRTC·버튼 System OFF
PASS는 유지하며, T13 UART21 DMA·peer 제어 결합의 미실기를 그 PASS로 바꾸지 않는다.

110번 요구 대조에서 다음 다섯 경계는 충분한 기존 증거, 필요한 추가 구현·실기 또는 명시적
지원 제한을 T14/T15에서 판정해야 한다. 문서 대조 1/1 완료가 이들의 실기 PASS는 아니다.

- SPI CS 조기 종료의 독립적인 slave frame 판정
- TWIS read-request 공급 지연과 복구
- 전체 GPIO alias·DMA overlap active 충돌
- 실제 GPIOTE/DPPI active 충돌과 기존 출력 보존
- Fabric PWM과 analogWrite/tone/Servo active 충돌·출력/buffer 보존
