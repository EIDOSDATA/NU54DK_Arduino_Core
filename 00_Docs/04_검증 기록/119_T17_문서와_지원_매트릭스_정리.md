## 1. 지원 원장 확정

| 범위 | T17 결과 |
| --- | --- |
| 전체 identity | 75 |
| `public`·HIL `pass` | 62 |
| M24 Serial | 23 public, route verified, `SerialFabric` |
| M25 Analog·Event·Stream | 34 public; PDM20/21·I2S20은 `StreamFabric` |
| QDEC20/21 | `internal`·HIL `partial`, `fabric` profile에서 **unsupported** |
| M26 System | 기존 radio/power 경계와 TEMP·WDT30·WDT31의 public API를 원장에 반영 |
| 나머지 system identity | 11개, 기존 근거에 따라 `internal` 또는 `none`; 공개 지원으로 승격하지 않음 |

T15의 `internal candidate`는 물리 지원 판정 시점의 상태였습니다. T16에서 별도 `fabric` profile을
만든 뒤 T17에서 지원 판정이 끝난 identity만 public으로 승격했습니다. 기존 singleton과 직접 Fabric
API는 같은 profile에서 섞지 않으며 QDEC 결과를 공개 지원으로 해석하지 않습니다.

| patch 공백 | `git diff --check` PASS |

기본 WinLibs 실행 파일은 이 PC의 Windows Application Control에 차단됐습니다. 같은 WinLibs sysroot를
명시한 LLVM compiler로 전체 Host 회귀를 다시 실행했습니다. 새 executable의 첫 시작만 간헐적으로
거부되는 경우는 프로세스가 시작되지 않았을 때에만 최대 2회 재시도합니다. 이 상한 뒤의 정책 차단,
컴파일·링크·실행 종료 코드와 assertion 실패는 그대로 실패시켜 코드 실패와 실행 환경 race를 분리합니다.
