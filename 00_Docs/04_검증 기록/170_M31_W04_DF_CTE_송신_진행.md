# M31-W04 기본 안테나 CTE 송신 진행

고정 NCS/Zephyr/NU54DK board revision에서 upstream Direction Finding 세 구성을
`nrf54l15dk/nrf54l15/cpuapp/nu54dk`로 개별 빌드했다.

| 구성 | Controller | native target 빌드 | Arduino·실기 |
| --- | --- | --- | --- |
| connectionless AoA CTE TX | 기본 SDC | PASS | 공개 `CteBeacon` build PASS, 20회 시작·중단과 잘못된 길이 20/20 거부 |
| connected CTE response TX | 기본 SDC | PASS | Arduino 역할·상대 보드 실기 미실행 |
| connectionless raw IQ RX | `bt-ll-sw-split` | PASS | W01 HCI RX bit 확인, 실제 IQ report 미수집 |

Arduino 송신 예제의 clean Core는 `53399559daa748b07539025c1ab64bb6464c7788`이며
image SHA-256은 `f11655cea3598a586eabcb85de129d29646bdcf149ac31b950cd0758c3109a8c`이다.
CMSIS-DAP V2의 DP/AP register identity를 확인하고 sector flash와 hardware reset을 거쳤다.
Serial 128-bit nonce를 매 cycle 검증해 20/20 `STARTED`, 20/20 `STOPPED`, 20/20
`REJECTED`를 기록했다. [Arduino 빌드 manifest](evidence/m31-w04-df-53399559/df-arduino-build-manifest.json),
[실기 JSON](evidence/m31-w04-df-53399559/df-beacon-01.json),
[UART 원본](evidence/m31-w04-df-53399559/df-beacon-01.transcript.log),
[native 빌드 manifest](evidence/m31-w04-df-53399559/df-native-build-manifest.json)를 보존했다.
압축된 native log·HEX 3쌍의 원본 SHA-256은 manifest와 일치한다.

이 실기는 **CTE 설정 명령 수락과 광고 수명주기**를 증명한다. RF에서 실제 CTE를 수신했다는
증거는 아니므로 readiness의 `M31-DF-01` 기능 HIL은 `NOT_RUN`이다. 또한 고정 Zephyr Host의
AoA RX 설정 경로는 두 안테나와 RX antenna switching feature를 검사한다. 1안테나 NU54DK의
raw IQ 경로는 현재 native build·HCI bit까지만 확인했으며, 실제 두 보드 report 수신과
우회 가능성은 W04의 남은 조사·실기 항목이다. 수신 IQ를 확인하더라도 각도 계산의 증거로
승격하지 않는다. connected responder의 Arduino 예제와 상대 역할도 남아 있다.
