# T12 QDEC 누산 누락 원인 분리

2026-09-08 KST, [100번 공통 묶음](100_T12_공통_기능_묶음과_T13_조합_확정.md)의 후속이다.
QDEC 추가 240조건은 미완료다. 실제 입력과 개별 SAMPLE은 맞지만 동작 중 누산 read/clear에서

현재 로컬 hal_nordic은18da0cc9726f8759c627dba3180b3ba9294e433c다.
`nrfx_qdec_init`은 reportper_inten이 참일 때만 shortcut을 켜고, IRQ handler는 활성 mask를
적용한다. `nrfx_qdec_accumulators_read`는 READCLRACC task 후 ACCREAD/ACCDBLREAD를 읽는다.
해당 `nrf_barrier_*`는 이 ARM 빌드에서 DSB를 수행하지 않는다. 이것만으로 barrier 부족을
원인으로 단정하지 않는다. SDK 파일은 변경하지 않았다.

## 다음 대비의 범위

`qdec-timing-diagnostic`은 같은 image에서 방법 0(공개 read), 3(동일 task 뒤 DSB를 넣은
HAL 진단), 4(새 SAMPLE 관측 후 32~64µs에 공개 read)를 각 30회 비교한다.
방법 4는 진단의 고정 256µs 샘플 조건에서만 사용하고, IRQ를 잠근 상태에서 새 SAMPLE을
4µs 간격으로 관측하되 대기는 1024µs로 제한한다. GPIO/SAMPLE 관측과 기존 포화·lease·STOP
검사를 유지한다. 이 시험의 기다리는 방법을 제품 API로 채택한 것이 아니다.
page6에 read 시 SAMPLE 관측 경과의 최소/최대µs와 최대 대기µs를 기록한다.
기대 카운트는 보정하지 않으며 실패 원본을 유지한다. 이 대비도 기능240 또는 T13 실기 PASS가 아니다.
