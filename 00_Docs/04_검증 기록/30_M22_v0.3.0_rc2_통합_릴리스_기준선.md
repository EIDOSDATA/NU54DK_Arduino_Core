## 1. 결과 요약

M22 RC2는 AC-01~AC-03과 M19~M21의 개발 결과를 library 8개·Arduino 예제 29개의 설치
package로 통합하고, 공개 Boards Manager URL을 통한 전체 설치 수명주기를 검증했습니다.
판정 상태는 `public-rc2-validated`, 결과는 `passed`입니다.

- 두 번의 독립 package 생성: **byte-identical PASS**
- Host software/release contract: **PASS**
- 실제 archive 설치본 예제: **29/29 compile PASS**
- 설치본 Blink 지정 CMSIS-DAP Upload: **pyOCD 실제 보드 PASS**
- Public RC2 URL 기반 동일 PC 격리 clean-room: **전체 lifecycle·cleanup PASS**
- GitHub Actions software/reproducible workflows: **PASS**
- Stable `v0.2.0` index: **크기·SHA-256·Git blob 불변**
- Stable `v0.3.0`: **아직 공개하지 않음**

RC1 clean-room 중단 원인은 tagged harness가 Nordic SDK와 Toolchain 설치 leaf를 먼저 만든
것이었습니다. RC2는 installer가 두 leaf를 직접 생성하도록 runner를 교정하고 새 source, plan,
tag와 evidence로 모든 필수 gate를 다시 실행했습니다. RC1의 PASS 또는 실패 evidence를 RC2
판정으로 복사하지 않았습니다.

## 6. Public clean-room와 cleanup

Clean-room은 공개 RC index와 공개 archive만 사용해 격리된 Arduino/NCS/Toolchain 환경에서 다음
순서를 완료했습니다.

1. Nordic Toolchain과 NCS v3.4.0을 새 install leaf에 설치
2. `0.3.0-rc.2` Core 설치와 예제 29/29 compile
3. 설치본 Blink compile과 지정 CMSIS-DAP pyOCD Upload
4. Stable `0.2.0` downgrade
5. RC2 upgrade
6. Core uninstall 뒤 격리 NCS/Toolchain 유지 확인
7. RC2 reinstall과 Arduino 예제 재발견 확인
8. 외부 evidence/log 보존 뒤 exact run leaf만 정리

Cleanup 전에 evidence를 외부 경로로 보존하고 run marker, ID/token, reparse point 부재와 삭제
대상을 검증했습니다. Windows read-only 속성이 남은 NCS Git 파일 234개는 승인된 exact run leaf
안에서만 속성을 복구한 뒤 정리했습니다. 성공한 exact leaf는 제거됐고 sibling, parent 밖 경로,
현재 사용자의 기존 Arduino/NCS/Toolchain 환경은 변경하지 않았습니다.

## 7. Stable 불변 guard

RC2는 별도 per-tag index만 사용했습니다. 실행 전후 stable index는 다음 identity와
byte-for-byte 동일합니다.

| 항목 | 고정 값 |
| --- | --- |
| Stable index | `package_nucode_nu54dk_index.json` |
| 크기 | 1,877 byte |
| SHA-256 | `5ae7fbe13f71c52950879064685694cf4b062557572f187e81476639724e5344` |
| Git blob | `b2a3ac2d4c3babf366541406764e5f900f2f4e6d` |
| Stable version 순서 | `0.2.0`, `0.1.0` |

따라서 현재 production stable은 계속 `v0.2.0`입니다. RC2 공개 검증 완료는 `v0.3.0` stable
승격 또는 stable index 변경을 뜻하지 않습니다.

`v0.3.0-rc.2`는 exact source와 board gitlink, byte 재현 package, 7개 공개 자산, 설치본 예제
