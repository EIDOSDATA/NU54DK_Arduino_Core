# 249 — M31 P2 문서 정합성·가독성 감사

## 감사 범위

`README.md`, `AGENTS.md`, `00_Docs/README.md`, `HANDOFF.md`,
`TODO_M31.md`, `TODO_v0.5.0.md`, 메모리 최적화 통합 설계와 검증 기록
색인을 현재 상태의 진입점으로 검토했다. P2의 238~248번 기록은
부하 분모·이미지·종료·한계를 대조했다. 과거 기록의 당시 판정과
실패 원본은 현재 상태로 덮어쓰지 않았다.

작업 디렉터리의 Markdown 410개를 열거했다. 이 중 메인 저장소 문서 404개에
UTF-8·로컬 링크 검사를 실행했고, board submodule의 문서 6개는 해당
저장소 소유 범위라 수정·gate 판정에서 제외했다. 현재 진입점의
M31 3/8, P0·P1 완료, P2 미완료, W04/W05 미완료, Windows-only
v0.5.0·HOST 보류 문구를 검색·대조했다. 장문의 상태 표를 간결하게
나누고, 최신 CS/DF/Audio/SDC 결과에서 보존 원본으로 가는 링크를
추가했다. 새 P2 JSON은 구문을 검사하고 원시 probe UID 문자열이
들어 있지 않은지 확인했다.

| 검사 | 결과 |
| --- | --- |
| Markdown UTF-8·로컬 링크 | `tools/ci/run_m12_gate.py docs` 메인 저장소 문서 404개 PASS. board submodule 문서 6개는 별도 범위다. |
| 전체 Host 회귀 | `tools/release/run_fixed_gate.py host` 1,492 tests, 2 skip, PASS. CS·Audio 부하 인자 테스트를 포함한 최종 전체 재실행이다. |
| P2 실물 원본 | CS 장기 진단의 누락·실패, DF 연결형 PASS와 connectionless HOLD/FAIL, Audio 10,000 frame PASS를 서로 다른 판정으로 유지한다. |
| 공개 범위 | P2·M31-W04/W05/W06 또는 v0.5.0 공개 완료를 주장하지 않는다. |

자동 gate는 모든 문장의 기술적 진위를 보증하지 않는다. 수치가 변하면
원본 JSON·image hash·해당 기록을 먼저 갱신하고, 이 색인과 현재
진입점의 요약을 맞춘다.
