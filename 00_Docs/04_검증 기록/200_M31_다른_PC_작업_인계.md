## 다른 PC에서 재개하는 절차

1. **실제 저장소를 C drive에서 사용**한다. 이전 PC의 `C:/~/...` staging, 빌드 HEX,
   Arduino CLI config, prerequisite marker, COM 번호·probe mapping은 Git으로 옮겨지지 않는다.
   저장소 루트에서 `git status --short --branch`, `git remote -v`, `git fetch origin`,
   `git switch m31-w01`(branch가 없으면 `git switch --track origin/m31-w01`),
   `git pull --ff-only`, `git submodule update --init --recursive` 순으로 확인한다.
   미커밋/분기 충돌은 보존하고 덮어쓰기·reset/rebase·강제 push를 하지 않는다.
2. `AGENTS.md`, [HANDOFF](../HANDOFF.md), [M31 TODO](../TODO_M31.md),
   [전체 기능·예제 계약](<../01_아두이노 코어 설계/19_NCS_Bluetooth_전체_기능과_예제_실행_계약.md>),
   이 기록과 197~199번, M31 readiness·sample parity를 읽는다. `git rev-parse HEAD`와
   `git submodule status`로 lock을 대조한다. NCS/toolchain과 공식 prerequisite 검증은
   새 PC에서 다시 수행한다. b47a의 설치본 증거는 **독립 로컬 개발 package**이며 공개 릴리스가 아니다.
3. 새 설치본 검사가 필요하면 clean source에서
   `tools/ci/m31_iso_stage_package.py`로 독립 Sketchbook package를 만들고,
   `tools/ci/m31_iso_installed_examples.py`의 CLI 인수·고정 FQBN을 확인해 빌드한다.
   해당 스크립트는 기존 목적지와 dirty source를 거부한다. 전역 prerequisite marker의
   pins hash가 다를 수 있으므로 공식 `tools/nu54-prerequisites` 절차로 새 PC의 고정 입력을
   확인한다. 이전 PC의 별도 `LOCALAPPDATA`와 임시 ready marker를 복사하지 않는다.
4. 보드 시험 전에는 CMSIS-DAP V2 probe identity의 SHA-256, COM/serial, 역할,
   firmware revision을 **새 PC에서 다시 매핑**한다. 원시 UID·인증 정보는 Git 증거에 넣지 않는다.
   `auto_unlock=false`와 exact image를 사용하고, 원인 불명 실패는 연결·전원 확인 뒤
   register/log 근거로 진단한다. 시험하지 않은 기능을 PASS로 옮기지 않는다.
5. 다음 구현은 W03 잔여부터 시작한다. 역할별 `.ino`에서 일반 C/C++과 `NUCODE_*`
   공개 API로 사용자가 바꿀 수 있는 데이터·오류·종료 흐름을 보여준다. Zephyr 직접 호출은
   library `.cpp`/`src/internal`에 두고 공개 이름에 `M31` 같은 개발 표식을 넣지 않는다.
   W03-02 BAP unicast 근거는 보존한다. 독립 가능한 W04 raw IQ와 W05 CS 오류도 조사하고,
   이후 W06~W08 통합·회귀·완료 조건을 수행한다. 변경마다 관련 Host/빌드/HIL과
   readiness·TODO·검증 기록을 정확한 SHA로 연결하고 주기적으로 커밋·푸시한다.

이번 PC에서 수행한 두 staging 실패(누락 runtime manifest, 전역 prerequisite pins 불일치)는
[199번](199_M31_W02_격리_설치본_ISO_11예제와_완료.md)에 진단으로 보존했으며 최종 PASS에
합산하지 않았다. 독립 package를 수정해 전수 재실행한 증거가 최종 W02 판정이다.
이 인계에서는 CI/CD를 요청·조회·대기하지 않는다. 다음 PC에서도 새 사용자 지시가 없으면
같은 범위를 따른다.
