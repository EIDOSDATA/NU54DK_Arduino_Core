# M31-W04 기본 안테나 IQ 수신 진단

고정 NCS `v3.4.0`에서 connectionless AoA CTE 송신과 수신을 두 NU54DK로 대조했다.
모든 시도는 CMSIS-DAP V2 SHA-256 probe identity와 DP/AP register identity를 재확인한 뒤
sector flash·hardware reset을 사용했다. UART 주소를 익명화한 6개 시도의 image SHA-256,
변경 범위와 결과는 [진단 manifest](evidence/m31-w04-df-rx-diagnostic-8d64d915/diagnostic-manifest.json)에
있다. 수신 코드는 고정 upstream sample을 C 드라이브 임시 위치에 복사해 진단용으로만
변경했으므로 `source_clean=false`이고 Arduino 기능 HIL PASS의 근거로 사용하지 않는다.

| 수신 구성 | 확인한 범위 | 결과 |
| --- | --- | --- |
| Zephyr LL, AoA RX, 대상 이름만 출력 | Arduino `CteBeacon`의 extended advertisement를 RSSI 약 -38~-47 dBm으로 수신 | periodic sync 반복 시간 초과; `sys_dlist_remove`/`z_abort_thread_timeout` 경로 bus fault |
| Zephyr LL, AoA RX, CTE-only sync option 제거 | 같은 광고와 periodic interval `0x03c0` 확인 | sync 시간 초과와 삭제 오류 |
| 기본 SDC, periodic scanner | 같은 Arduino 광고로 periodic sync 수립, LE 2M/1200 ms 확인 | **periodic 수신만 확인**. CTE RX 함수 호출을 제거한 진단 image이며 IQ 검증 아님 |
| Zephyr LL, DF 기능 없이 periodic scanner | 같은 광고로 여러 차례 재시도 뒤 periodic sync 수립 | LL의 일반 periodic 수신 가능성 확인. IQ 검증 아님 |
| Zephyr LL, AoA RX, sample timeout 단위 수정 | 같은 광고를 수신 | sync 시간 초과 뒤 `sys_dlist_remove`/`z_abort_thread_timeout` 경로 usage fault |
| upstream native AoA TX + Zephyr LL AoA RX | native TX의 CTE/periodic/extended 시작 수락과 RX의 extended advertisement 확인 | periodic sync 미수립; IQ report 없음 |

고정 upstream locator sample은 `BT_GAP_US_TO_PER_ADV_SYNC_TIMEOUT()`이 반환하는 **10 ms 단위**
값을 `K_MSEC(sync_create_timeout)`에 바로 넣는다. 이 때문에 application 대기 시간이
controller timeout보다 10배 짧다. `K_MSEC(sync_create_timeout * 10U + 2000U)`로 임시
수정한 재시험에서도 sync가 실패했고 삭제 중 fault가 발생했다. 단위 오류가 조기 삭제에
기여하지만, 현재 LL AoA RX 실패의 유일한 원인으로 단정하지 않는다. fault PC는 고정 ELF의
`sys_dlist_remove` (`dlist.h:530`), LR은 `z_abort_thread_timeout` (`timeout_q.h:87`)으로
해석했다. SDK 원본은 변경하지 않았다.

고정 Zephyr Host의 `valid_cte_rx_common_params()`는 AoA RX에서 안테나 2개 이상과
`BT_FEAT_LE_ANT_SWITCH_RX_AOA`를 요구한다. 현재 1안테나 보드는 이 경로를 통과하지
않는다. LL controller 쪽은 antenna-switch 설정이 없으면 switch pattern 검사를 생략하지만,
이 코드만으로 IQ 수신 성공이나 지원을 판정하지 않는다. 현재 `raw_iq_rx`는
**source candidate / 기능 HIL NOT_RUN**이며 정확한 상한은 Host와 LL controller의
동기화·report 경로를 추가 실기로 확인해야 한다. 기본 SDC의 CTE 송신 광고가 전파로
수신됐다는 사실을 CTE IQ·AoA 각도 계산 PASS로 확대하지 않는다.
