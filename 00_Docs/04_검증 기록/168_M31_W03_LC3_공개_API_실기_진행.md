이 예제의 `.ino`는 합성 PCM 생성과 공개 `Lc3Codec` 호출, 결과 검사, 오류 처리를 보여 준다.
liblc3 자료형과 구현은 라이브러리 `.cpp` 안에 있으며 `.ino`에서 Zephyr를 직접 호출하지 않는다.
고정 메모리의 16 kHz·10 ms·40-byte frame을 사용한다. 손실 codec이므로 입력 PCM byte와
복호화 PCM byte의 동일성을 요구하지 않고 frame 수, 출력 checksum·energy와 오류 분모를 검사했다.

[정확한 빌드 manifest](evidence/m31-w03-audio-5219626b/audio-arduino-build-manifest.json),
[실기 JSON](evidence/m31-w03-audio-5219626b/audio-lc3-01.json),
[UART 원본](evidence/m31-w03-audio-5219626b/audio-lc3-01.transcript.log),
[빌드 로그](evidence/m31-w03-audio-5219626b/audio-build.log.gz)를 보존했다.
실기 JSON에는 익명 probe SHA-256, AP register, image SHA-256, 20개 nonce 및 원본 hash를 결합했다.
초기 clean `857641e1…`의 동일 시험 원본도 별도 evidence directory에 보존했다.

이 결과는 **보드 내부 encode/decode** 증거다. W03-01의 합성 PCM → encode → ISO 무선 전송 →
상대 보드 decode, peer loss·복구와 BAP codec/QoS 설정은 아직 입증하지 않았다. 이 때문에 readiness의
W03-01 `functional_hil`과 Audio family case를 PASS로 승격하지 않았다. 다음 단계에서 BAP unicast
양 역할과 ISO data path를 연결해 별도 exact image로 검증한다.
