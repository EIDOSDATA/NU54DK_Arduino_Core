## 3. Runtime과 승인 경계

stable runtime fingerprint는
`e6d205e261328c842a164762f1df1ff010b0a209319c925df89ee797ad99f659`이며 공개
`v0.1.0-rc.2`와 일치한다. stable package의 runtime 입력 변경은 `platform.txt` version
표기뿐이다. license inventory의 프로젝트 승인 상태는
`project-owner-approved-for-final-public-release`다.

프로젝트 소유자가 확인한 별도 clean Windows Arduino IDE 설치·compile·실제 NU54DK
upload·실행은 rc.2 수동 검증 기록이다. 이 결과를 stable exact HIL로 소급 표기하지 않는다.
stable 공개 검증은 exact archive·index·checksum·runtime 동등성까지 자동 확인했다.
