# 274 — v0.5.0 정식 릴리스 승인과 공개

## 결정

2026-09-27 프로젝트 소유자는 RC2 사용자 시험에서 Standard Blink의 250 ms → 100 ms 연속 Upload가
USB 재연결 없이 성공한 것을 확인했다. 이어 모든 요구사항과 자격요건이 충족됐다고 판단하고 정식
`v0.5.0` 공개, `v0.4.1` 이후 이력 Squash, 모든 문서 검토, main 반영, `Release-0.5.0` 백업 브랜치와
`0.5.0-RC1`·`0.5.0-RC2` branch 삭제를 명시적으로 승인했다.

## 보존과 게시 계약

- RC1/RC2 tag·GitHub Pre-release·asset과 과거 검증 evidence는 변경하거나 삭제하지 않는다.
- v0.5.0 package는 RC2 asset을 재명명하지 않고 최종 exact commit에서 두 번 생성해 byte를 비교한다.
- stable root catalog는 지원 버전 0.5.0 하나만 제공한다.
- stable tag·Release·asset 공개 뒤 public byte를 다시 다운로드해 plan과 비교한다.
- 승인 evidence는 exact target commit과 stable plan SHA-256에 결합한다.
- root catalog 게시 commit과 공개 결과 마감 commit은 tag source 뒤에 올 수 있으며, package manifest와
  tag target은 동일한 Squash commit으로 고정한다.

공개 smoke는 실제 보드 Upload를 반복하지 않았다. 실제 Arduino IDE에서는 사용자가 runtime PM 교정을 적용한 RC2 설치본으로
Standard Blink 250 ms를 Upload한 뒤 100 ms로 바꾸어 USB 재연결 없이 연속 Upload 성공을 확인했으며,
같은 runtime PM 수정이 정식 source에 포함됐다. 공개 자산과 설치 상세는
[`v050-public-20260927`](evidence/v050-public-20260927/) evidence에 고정한다.

## Git 마감

`v0.4.1` 이후 제품 변경은 정식 source commit 하나로 Squash했고 `v0.5.0` tag는 그 commit을
가리킨다. Root index와 공개 결과 원장은 후속 main 마감 commit으로 보존한다. `Release-0.5.0`은
최종 main 마감 commit과 같은 위치에 만든 백업 branch이며, 과거 `0.5.0-RC1`·`0.5.0-RC2`
branch는 로컬과 origin에서 삭제했다. RC tag·GitHub Pre-release·asset·evidence는 보존했다.

## 공개 후 CI 마감

`ed5fb745a72d3492a41c52598cbd7ddd2b596484`의
[M12 실행](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/36311841085)은 6개 대표
build 단계까지 성공한 뒤 NCS/toolchain cache 저장 중 25분 제한으로 취소됐다. 전체 CI PASS가 아니다.
`7a343b4f336563cd9423d4c2c43a2a039034fe86`에서 job 제한을 45분으로 보정했으며
[후속 M12 실행](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/36313276335)은
8개 job 성공·대표 build 1개 생략으로 전체 성공했다. Workflow 제한값만 바뀌어 분류기가 대표
build를 생략했으므로 앞선 build 증거와 이 실행의 성공 범위를 구분한다.

이 시점의 main과 `Release-0.5.0`은 모두 `7a343b4f`였다. 이후 문서 보완은
[275번](275_v0.5.0_공개_후_문서_전수_재검토.md)에 기록하며, 정식 tag source와 공개 자산은 유지한다.
