# 236 — M31 메모리 최적화 P1 역할별 잔여 pool 감사

## 1. 범위

P1-13 뒤의 adaptive BLE 10역할 fresh ELF와 실제 `CustomGattCentral` adaptive/full
ELF를 다시 대조했다. 정적 RAM 전체 숫자만으로 중복 저장소를 단정하지 않고, 최종
`.config`, source graph, ELF symbol 크기와 해당 기능의 수명 계약을 함께 본다.

| 이미지 | 관찰한 NUCODE 정적 저장소 | 판정 |
| --- | --- | --- |
| 1×1 GATT server | event queue 1,664 B, slot 392 B, shared TX state 144 B | client `states` 없음 |
| 실제 GATT Central adaptive | scan result queue 2,496 B, GATT event queue 1,536 B, client `states` 680 B | server `slots`·periodic·PAwR queue 없음 |
| 실제 GATT Central full | scan 2,496 B, periodic 2,240 B, PAwR 2,144 B, GATT event 4,416 B | 명시적 full 호환 구성에서 유지 |
| CoC-only | TX net_buf 2,092 B, RX net_buf 1,046 B | 512 B SDU·2 channel 계약 유지, 범용 GATT event queue 없음 |
| ISO CIS central | 작은 전용 transmit pool, 2 stream role | 범용 GATT/scan/periodic/PAwR queue 없음 |
| Audio unicast source | audio TX net_buf 1,040 B | source 전송 경로에서만 유지 |
| CS initiator | local step net_buf 4,352 B | initiator에서만 유지, reflector에는 없음 |

scan result queue는 공개 `BLEScanResult`의 최대 255 B payload와 8개 record를
보존한다. Kconfig 도움말의 과거 31 B 표기는 실제 객체·ELF와 달라 255 B로 정정했다.
scan/periodic/PAwR queue는 설정값 하나만으로 항상 들어오는 것이 아니라, 사용
source·reference까지 남아야 ELF에 존재한다. 실제 10역할 image에서
`forbidden_symbols`는 0건이다.

## 2. 회귀 문턱

기존 비활성 scan/periodic/PAwR/NUS/GATT/CoC/Security 저장소 검사에 더해,
최종 설정에서 `CONFIG_NUCODE_BLE_GATT_SERVER`가 꺼져 있으면 server `slots`,
`CONFIG_NUCODE_BLE_GATT_CLIENT`가 꺼져 있으면 client `states`,
`CONFIG_NUCODE_BLE_CS_INITIATOR`가 꺼져 있으면 initiator 전용 `local_steps`
symbol이 ELF에 남지 못하게 한다. 데이터 symbol만 검사하고 함수의 존재 자체를
잘못된 RAM 판정으로 확대하지 않는다.

| 검증 | 결과 |
| --- | --- |
| 새 forbidden-symbol Host 계약 | 44건 PASS |
| adaptive BLE 10역할 fresh build·기존 forbidden-symbol 감사 | 10/10 PASS, 0건 |
| 추가 방향·CS gate의 실제 ELF 대조 | PASS, adaptive 10역할의 symbol matrix 및 Central·Peripheral adaptive/full·CS initiator/reflector 6개 실제 `.config`+ELF 직접 판정 |
| 전체 Host suite | PASS, 1,481건 실행(2 skip) |
| 문서 UTF-8·내부 link gate | PASS, 392개 문서 |
| 물리 HIL | NOT RUN — 정적 ELF/source/config 역할 분리 감사 |

## 3. 남은 경계

CoC 512 B SDU, CS 최대 step, scan/event queue depth를 수치만 보고 줄이지 않는다.
burst 중 결과 유실, prepare/reassembly 실패, 절차 단편화가 있는 최악 조건은 실제
부하·overflow 계측을 거쳐야 한다. `malloc_arena`, main/BT/workqueue stack,
controller pool과 Zephyr heap의 축소도 P2다. P1은 이 항목을 실패가 아닌
계측 대기 경계로 남긴다.
