## 연속 stream·측정 준비

SAADC는 내부 VDD/AVDD의 2ms SAMPLE·32 sample 두 DMA slot, I2S는 48kHz stereo32bit
256 word 세 slot, PDM은 16kHz mono 1024 sample 네 slot을 구현한다. 반환 slot·길이·앞뒤 guard와
모든 sample/word를 검사한다. I2S는 시작 padding 이후 전역 위치를 계속 대조한다.
PDM peer는 첫 1024byte DMA 뒤 ORC 0x55의 50% 밀도 신호를 계속 공급하며 ORC를 DMA 완료로 세지 않는다.
PWM은 B의 1kHz loop를 A GPIOTE/DPPI/TIMER22로 받아 모든 에지의 교대·HIGH/LOW 간격을 검사한다.
CPU가 늦게 읽어 에지를 놓친 경우에도 실패를 유지한다.

Host는 두 보드의 engine·lane·stream raw를 모두 저장한 뒤 판정하고, 실패 후 STOP과 GPIO 반환을
각각 기록한다. 지연은 queue 호출 구간, API 제출부터 완료 event를 관측한 구간 및 service 실행 구간의
16-bin histogram/max/합계다. 실제 IRQ 진입 지연·순수 CPU 사용률의 측정으로 확대하지 않는다.
이 구현의 준비 검사·새 exact source 실기 결과는 후속 절에 기록하며 아직 PASS를 선기입하지 않는다.
