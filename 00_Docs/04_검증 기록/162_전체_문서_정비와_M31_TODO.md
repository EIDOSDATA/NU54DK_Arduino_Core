## M31 실행 순서

세부 수락 조건과 장비 경계는 [M31 TODO](../TODO_M31.md)가 단일 작업 목록이다.

1. `M31-W01`: 고정 SDK capability 원장, 지원·비지원 경계와 test ID를 확정한다.
2. `M31-W02`: raw ISO transport와 오류·lifecycle 계약을 구현한다.
3. `M31-W03`: LE Audio/BAP 경로를 ISO transport 위에 구현한다.
4. `M31-W04`: Direction Finding의 AoA 구현과 실기 경계를 확정한다.
5. `M31-W05`: connected Channel Sounding 구현과 거리·감쇠 fixture를 검증한다.
6. `M31-W06`: 동시 사용·회귀·resource conflict를 닫는다.
7. `M31-W07`: 실제 RF·상호운용 시험을 수행한다.
8. `M31-W08`: 문서·예제·회귀를 닫고 M32로 인계한다.

`HOST-W04~HOST-W06`은 M31과 병행할 수 있지만 M31의 W 번호가 아니다. Ubuntu prerequisite와
path/권한, macOS prerequisite와 architecture/permission, CI matrix 구현을 뜻한다. 실제 Ubuntu·
Apple Silicon macOS 설치·USB upload·serial·debug는 장비가 있는 후속 Host gate에서 판정한다.
