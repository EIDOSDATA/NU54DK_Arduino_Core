# 275 — v0.5.0 공개 후 문서 전수 재검토

## 범위와 기준선

2026-09-27 사용자는 문서 최신화 누락을 확인한 뒤 모든 문서를 수정하고 commit·push하도록
요청했다. 기준선은 `main`의 `7a343b4f336563cd9423d4c2c43a2a039034fe86`이며 작업 트리는
깨끗했다. `Release-0.5.0`도 같은 commit이고 board gitlink는
`fe65f2f0880bd05b32e562d9bf1ee59142b4f4d3`이다.

기존 감사 원장의 458개 문서와 현재 파일 hash는 일치했지만, 이는 내용의 최신성까지 보증하지
않았다. `TODO_v0.4.0.md`의 현행 지원 안내에 v0.4.1·RC2가 남았고 README와 Git 마감 안내에도
이전 채널·예정 표현이 남아 있었다. 이번 작업은 본문을 다시 검토해 현재 안내와 역사 기록을
구분하고 정식 v0.5.0 기준으로 동기화한다.

## 보존 경계

- 현재 지원·설치 대상은 Windows 10/11 x64용 v0.5.0 하나다.
- RC1/RC2 branch 삭제와 `Release-0.5.0` 생성은 완료 상태로 안내한다.
- 과거 시험의 source·수치·PASS/FAIL/HOLD/NOT RUN과 공개 tag·Release·자산은 보존한다.
- M32/M33은 미착수이며 HOST-W04~W08의 사용자 보류 상태를 유지한다.
- board·third-party 원본, 회로도·라이선스 전문·원시 evidence는 변경하지 않는다.

검토 대상별 결과·hash와 검사 결과는 [문서 감사 원장](../document-review.json)에 기록한다.

## 수정 내용

- README·개발/설치 안내·TODO·인계 문서의 현행 지원과 설치 경로를 정식 v0.5.0으로 맞췄다.
- API 지원표와 기능/예제 목록에 M28~M31의 구현·검증 범위를 반영하고, ISO·Channel Sounding·
  DFU의 오래된 미지원 표현을 교정했다. experimental·미지원·별도 fixture 경계는 유지한다.
- 과거 릴리스에는 지원 종료와 역사 문서 안내를 붙였다. 당시 버전·명령·시험 결과는 현재 결과로
  덮어쓰지 않고, 후속 완료/공개 기록을 별도로 연결했다.
- 검증 기록의 중간 HOLD·FAIL·NOT RUN을 PASS로 바꾸지 않았다. 후속 성공과 현재 상태를 구분했다.
- 생성 문서인 M24 안내는 renderer의 버전 문구를 수정한 뒤 재생성해 원본과 산출물을 일치시켰다.
- 기존 CI 기록에서 build 단계 성공, cache 저장 중 job 취소, 후속 실행의 build 생략을 구분했다.

## 검토 방법과 한계

본 저장소 Markdown 453개와 고정 board submodule Markdown 6개, 총 459개를 목록과 대조했다.
전체 본문을 대상으로 현행 버전·지원·설치·기능·완료 상태를 검색하고 관련 문맥과 구현/배포 근거를
검토했다. UTF-8·상대 링크·생성 문서·정규화 hash는 별도 자동 검사했다. 유지가 적절한 문서와
외부 원본은 불필요하게 바꾸지 않았다.

이 검토는 과거 모든 기술 문장·측정값의 독립적인 재실험을 뜻하지 않는다. 공개 tag·ZIP·첨부 릴리스
문서는 당시 byte를 보존하며, 최신 보완 설명은 main 문서에 반영한다. 새 보드 시험은 수행하지 않았다.

고정 board submodule의 `03_PINOUT.md` UART 표에는 core의 소유자 확정 P2 번호와 차이가 있다.
상위 원본은 변경하지 않으며 실제 결선은
[core 커넥터 기준](<../01_아두이노 코어 설계/13_NU54DK_P2_P4_커넥터_핀맵.md>)과
그 기계 판독 JSON을 따른다. 외부 문서를 보존했다는 사실은 그 내용 전체를 현행 core 지침으로
승인했다는 뜻이 아니다. 이번 작업에서 핀 값이나 결선은 변경하지 않았다.

## 로컬 검증과 Git 마감

문서 UTF-8/상대 링크 검사, peripheral 생성 문서 대조, M24 계약 검사와 host 단위시험 17개,
coverage 문서 재생성 비교, M31 계약 검사, whitespace 검사는 PASS했다. M12 CI 계약 46개와
inventory gate, M28/M29 readiness 16개, M30 readiness 7개, M31 외장 audio 계약 4개도 PASS했다.
단위시험은 새 물리 실기를 뜻하지 않는다. 최종 문서별 정규화 SHA-256은 감사 원장에 기록한다.

별도 교차 검토에서는 변경 문서의 역사 hash 제거·치환과 과거 판정 승격 여부를 확인했다.
문서 gate가 검사하지 않는 절 링크도 대조해, TODO 제목 변경으로 깨진 M31 설계의 참조를
교정했다. 확인한 로컬 fragment 링크는 본 저장소 88개·board submodule 3개이며 미해결 항목은 없다.

문서 마감 commit은 main에 push하고 `Release-0.5.0` 백업도 같은 commit으로 동기화한다.
push 후 해당 exact SHA의 CI 결과를 확인해 최종 작업 보고에 남긴다. 앞선 source의 CI 성공을
이번 문서 commit의 성공으로 재사용하지 않는다.
