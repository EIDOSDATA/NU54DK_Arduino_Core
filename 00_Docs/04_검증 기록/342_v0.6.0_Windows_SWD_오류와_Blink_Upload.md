# v0.6.0 Windows SWD 오류와 Blink Upload

2026-11-24 KST에 Windows 11 Pro x64(빌드 26300), Arduino IDE 2.3.11에서 공개 v0.6.0 설치본의 Blink Upload를 검증했습니다. 제품 소스는 `0a63c501ccd0d2e26298f1ad98a81a99cddc565f`입니다. NCS v3.4.0과 Blink Verify 결과는 [341번 기록](341_v0.6.0_Windows_SDK_복구와_Blink_Verify.md)에 있습니다.

## 실패와 USB 장치 재인식

| 시각 (KST) | 관찰 결과 |
| --- | --- |
| 05:42~05:46 | Blink 빌드는 완료됐고 Upload는 여섯 번 실패했습니다. pyOCD가 CMSIS-DAP 프로브를 인식한 뒤 MCU의 디버그 접근 포트(AP)를 탐색하던 중 `No ACK`, `Unexpected ACK` 또는 `FAULT ACK`를 기록했습니다. 각 시도의 종료 코드는 `1`이었습니다. [Blink Upload 실패 로그](evidence/windows-v0.6.0-swd-blink-upload/blink-upload-failed.log) |
| 05:50, 05:51 | IDE를 다시 실행한 뒤 빈 스케치 `sketch_nov24a`도 같은 프로브에서 두 번 실패했습니다. [빈 스케치 Upload 비교 로그](evidence/windows-v0.6.0-swd-blink-upload/empty-sketch-upload-comparison.log) |
| 05:53:39 | Windows의 `DEVPKEY_Device_LastArrivalDate`에서 `CMSIS-DAP v2`와 COM17·COM18이 같은 시각에 다시 인식된 것을 확인했습니다. `CMSIS-DAP v2`의 드라이버 서비스는 `WINUSB`, 장치 문제 코드는 `0`이었습니다. |
| 05:54:05 | 직전 두 시도와 같은 빈 스케치 HEX가 같은 프로브에서 종료 코드 `0`으로 업로드됐습니다. [빈 스케치 Upload 비교 로그](evidence/windows-v0.6.0-swd-blink-upload/empty-sketch-upload-comparison.log) |

USB 장치 재인식 후 고정 툴체인의 pyOCD 0.42.0으로 MCU에 연결해 Cortex-M33 CPU ID `0x411fd210`을 읽었습니다. CMSIS-DAP v2 기본 1MHz, v2 100kHz, v1 HID 1MHz, v2 1MHz 단일 패킷 전송이 각각 통과했습니다. [SWD 읽기 진단 로그](evidence/windows-v0.6.0-swd-blink-upload/swd-read-only.log)

**최초 SWD 오류 원인은 미확정입니다.** 실제로 확인한 전후 변화는 Windows USB 장치 재인식과 동일 HEX의 Upload 성공입니다. `Board ID 5415 is not recognized` 경고는 성공한 Upload에도 표시됐습니다. [USB 재연결과 재시도 절차](<../05_릴리스/v0.6.0/TROUBLESHOOTING.md#windows에서-swd-통신-오류가-날-때>)

## Arduino IDE Blink Upload 성공

IDE에서 `File > Examples > NUCODE NU54DK > Blink`를 열고 `NU54DK (nRF54L15, Zephyr)`, `Standard peripherals`, 기본 CMSIS-DAP으로 Upload를 실행했습니다. 05:58:02에 종료 코드 `0`과 IDE 출력 `NU54_UPLOAD_PASS runner=pyocd`를 확인했습니다. 20개 섹터를 지우고 81,920바이트를 기록했습니다. [Blink IDE Upload 성공 로그](evidence/windows-v0.6.0-swd-blink-upload/blink-ide-upload-success.log)

성공한 Blink HEX의 SHA-256은 `fbab40838350c73fc8fdbefc96e49d25df97a752bd39ff788501fbb3605e0768`입니다. USB 장치 재인식 전에 실패한 Blink 시도 중 처음 세 건과 같은 해시입니다. 이 기록의 PASS 범위는 Windows IDE의 Blink Upload입니다. LED 점멸 관찰은 `NOT_RUN`입니다.

저장소에 첨부한 로그에서는 Windows 사용자명, 원시 프로브 식별자와 BLE 주소를 가렸습니다.
