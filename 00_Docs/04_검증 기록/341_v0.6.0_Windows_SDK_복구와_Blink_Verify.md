# v0.6.0 Windows SDK 복구와 Blink Verify

2026-11-24 KST에 Windows 11 Pro x64(빌드 26300)에서 공개 v0.6.0 설치본의 SDK 준비 상태를 복구하고 Arduino IDE 2.3.11에서 Blink **Verify**를 통과했습니다. **해결 완료** 범위는 이 PC의 SDK 설치와 IDE 컴파일입니다. 보드 Upload와 LED 동작은 `NOT_RUN`입니다.

| 항목 | 확인값 |

| 제품 소스 | 설치본 `release-manifest.json`과 제품 태그 `v0.6.0`이 `0a63c501ccd0d2e26298f1ad98a81a99cddc565f`로 일치 |
| 초기 Python | 패키지 전용 `nu54-python` 도구 버전 `3.12.16-20261026.nu54.1`, 런타임 Python 3.12.16 |
| SDK 및 툴체인 | NCS `v3.4.0`, 리비전 `99553055607b2e9885fbc80ccd11fa9da81c2df0`, 툴체인 번들 `dcbdc366a1` |
| 계정 및 상태 폴더 | IDE와 일반 PowerShell은 같은 Windows 계정. 기본 경로 `%LOCALAPPDATA%\NUCODE\NU54DK_Arduino_Core\prerequisites` 사용 |
| 경로 재정의 | `NUCODE_PREREQUISITE_STATE_ROOT`와 `NUCODE_NCS_INSTALL_ROOT`는 확인한 PowerShell 프로세스·사용자·시스템 범위에서 미설정 |

## 설치 오류와 복구

1. 최초 IDE Verify는 `[NU54 1/5]`에서 `ready.json` 부재로 `[NU54:E_PREREQUISITE_READY]`, `exit status 2`를 반환했습니다. 상태 폴더에는 `incomplete.json`이 있었고 bootstrap은 검증을 마친 상태였습니다.
2. 05:30:54에 설치된 v0.6.0의 `post_install.bat`를 일반 PowerShell에서 실행했습니다. 기존 `host-prerequisites` 설치가 잠금을 보유하고 있어 수동 실행은 약 30초 후 `build lock 대기 시간이 초과되었습니다`와 종료 코드 `1`을 반환했습니다. [잠금 타임아웃 로그](evidence/windows-v0.6.0-blink-verify/post_install-v0.6.0.log)
3. 05:31:36에 기존 설치의 NCS 소스 아카이브 다운로드(약 2.88GiB)가 끝났고, 05:31:40에 설치기가 `ready.json`을 기록했습니다. 기존 프로세스 종료와 잠금 해제를 확인했습니다.
4. 05:32:24에 같은 훅을 다시 실행했습니다. 05:32:34에 종료 코드 `0`을 반환했고, 훅이 기록한 `ready.json`에서 `status=ready`, `ncs_version=v3.4.0`을 확인했습니다. 이때 `incomplete.json`은 없었습니다. [설치 훅 재실행 로그](evidence/windows-v0.6.0-blink-verify/post_install-v0.6.0-retry.log)

## Arduino IDE Blink Verify 결과

`File > Examples > NUCODE NU54DK > Blink`를 열고 `NU54DK (nRF54L15, Zephyr)`와 `Standard peripherals`로 Verify를 실행했습니다. 빌드 옵션의 FQBN은 `nucode:zephyr:nu54dk:upload_probe=pyocd,feature_set=standard`였습니다. IDE가 연 `Blink.ino`의 SHA-256은 설치 예제와 일치했습니다.

```text
[NU54] 컴파일과 링크: 320/320
[NU54 4/5] 링크와 firmware 생성
[NU54 5/5] 산출물·메모리 검증 완료: 157.4초
Sketch uses 81572 bytes (5%) of program storage space. Maximum is 1490944 bytes.
Global variables use 29439 bytes (11%) of dynamic memory, leaving 232705 bytes for local variables. Maximum is 262144 bytes.
```

Zephyr 빌드 로그에서 320번째 작업의 `zephyr.elf` 링크와 종료 코드 `0`을 확인했습니다. 저장소 로그 사본은 Windows 사용자명, 컴퓨터 이름과 잠금 토큰을 가렸습니다. [Blink 빌드 로그](evidence/windows-v0.6.0-blink-verify/blink-verify-build.log)

복구 안내를 추가한 `main` 커밋 `a216b38281d5fabb30cce628510b1039411003c9`의 M12 Software Gates는 전체 `success`로 완료됐습니다. 작업 8개가 성공했고 `Six Feature set representative builds`는 `skipped`였습니다. [GitHub Actions 실행 45257829120](https://github.com/EIDOSDATA/NU54DK_Arduino_Core/actions/runs/45257829120)
