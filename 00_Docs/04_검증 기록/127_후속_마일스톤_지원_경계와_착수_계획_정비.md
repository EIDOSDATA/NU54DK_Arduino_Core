# 후속 마일스톤 지원 경계와 착수 계획 정비

## 1. 요청과 변경 범위

- 날짜: 2026-09-12.
- 시작 source: `f778e9454532d8d0545523c6cad914453fc04b52`, branch `main`, 미커밋 변경 없음.
- Board gitlink: `fe65f2f0880bd05b32e562d9bf1ee59142b4f4d3` 유지.
- 소유자 요청: M28 이후 검토 결과를 관련 문서에 반영하고 로컬 커밋한다. 푸시는 요청 범위 밖이다.
- 소유자가 별도로 v0.4.0을 시험 중이므로 runtime, SDK, board, build 환경, 연결 장치와 공개 자산을 변경하지 않는다.
- 이번 작업은 공개 후 문서 유지보수다. M28~M45 구현·실기 착수 또는 지원 범위의 자동 승격이 아니다.

## 2. 정비 항목

1. M29 signed write의 deprecated 상태와 EATT의 experimental 상태를 지원 정책 결정에 연결한다.
2. M31의 AoA/AoD·IQ 수신 요구를 기본 controller 지원성과 구분하고, 기능군별 하위 판정으로 나눈다.
3. M32의 최소 radio 검증 기반과 M38/M39의 후속 제품화 범위를 연결한다.
4. M30 최소 BLE DFU와 M34~M36 보안·업데이트 확장의 인계 산출물을 구분한다.
5. v0.5.0 착수 계획에 기존 기능 회귀, 지원성 판정, 장비 확인, 수치 합격 기준의 확정 절차를 둔다.
6. 관련 로드맵·지원 매트릭스·빌드/저장소 안내·문서 진입점의 표현을 일치시킨다.

기존 Markdown 13개를 수정하고 착수 계획·이 기록 2개를 추가했다. 문서 삭제·이동은 없다.
기존 v0.4.0 API 계약·과거 시험 원본·릴리스 자산과 모든 비문서 파일은 변경하지 않았다.

M28~M45는 **계획·구현 미착수(완료 0/18)**다. 문서 정비 완료와 제품 개발 완료는 서로 다른 상태다.
