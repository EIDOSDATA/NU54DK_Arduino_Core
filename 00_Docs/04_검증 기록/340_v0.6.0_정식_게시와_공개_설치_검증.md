## macOS 27 공개 설치

macOS 27.2.1(26B131) Apple Silicon에서 Arduino CLI 1.5.1의 새 데이터, 다운로드, 사용자 디렉터리를 사용했습니다. CLI가 공개 인덱스를 직접 읽고 `nucode:zephyr@0.6.0`을 설치했습니다. 설치 파일 960개를 공개 ZIP과 대조했고 라이브러리 24개의 예제 204개를 확인했습니다. Blink와 BoardInfo 빌드를 통과했고, Blink BIN/HEX는 검증용 이미지와 같았습니다. 제거 후 공개 인덱스로 재설치했고 사용자 파일과 설치된 SDK를 확인했습니다.

이번 공개 검증에서는 USB 펌웨어 작업을 수행하지 않았습니다. 이전 배정 실기는 [OS 지원표](<../05_릴리스/v0.6.0/SUPPORT_MATRIX.md>)에서 확인할 수 있습니다. 로컬 공개 설치 증거 SHA-256은 `a281bd295bdf0c48cf8eec9c00fef44d44f3dee338d3298a5bc757d78942ca4c`입니다.

## 저장소와 CI

공개 설치 검증 이후 배포 브랜치 이름을 `Release-0.6.0`으로 변경했습니다. 제품 태그와 검증 기록 커밋은 각 용도에 맞는 SHA로 유지합니다. `main`에는 승인된 stable 인덱스 한 파일을 게시했습니다.

`main`의 CI는 6개 작업이 통과했고 3개 작업이 실패했습니다. Host unit과 패키지 검사에서 M10/M18의 v0.5.0 인덱스 크기 및 해시 고정값과 공개 v0.6.0 인덱스가 달랐습니다. 여섯 프로필 빌드는 Windows용 공식 nRF Util 다운로드의 해시 불일치로 설치 단계에서 중단됐습니다. 공개 인덱스의 v0.6.0 패키지와 세 Python 자산은 승인 계획의 해시와 일치했습니다.
