NU54DK Arduino Core v0.6.0의 최종 후보 준비를 이어간다.

1. AGENTS.md, 00_Docs/HANDOFF.md, 00_Docs/M33_HANDOFF.md, 00_Docs/TODO_M33.md의 W07 및 W08, 00_Docs/05_릴리스/v0.6.0/RELEASE_CHECKLIST.md를 읽는다.
2. 실제 checkout이 Dev-0.6.0-M33인지 확인하고 HEAD, 원격 브랜치, 미커밋 변경, board submodule을 기록한다. 최신 writer 해제 기록의 SHA와 이후 변경을 대조한 뒤 새 로컬 작업 경로에 단일 writer를 기록한다. 2026-11-16 Windows 전달 기록은 과거 인계용이다.
3. HOST-W07의 다섯 목표 행은 배정 검증을 완료했다. Host는 7/8, M33은 수락 6/8, 기술 완료 5/8이다. W06은 실제 PASS 46건과 사용자 수락 3건(#29, #40, #44)으로 마감했고 #29 분석은 유예한다.
4. C11의 macOS 26 및 27 실기는 336번과 337번을 확인한다. macOS 27의 일반 IDE Upload와 Blink 수정 검증은 C12의 338번에 있다. 소스 SHA와 kit 해시는 릴리스 문서의 README와 TESTING.md에서 확인한다. 원본 kit와 과거 실패 기록을 보존한다.
5. 정식 후보의 소스, 버전 식별자, OS별 자산, 라이선스와 출처, 재현성 및 변경 영향을 검토한다. NCS 3.4.0 및 고정된 보드/툴체인을 사용한다. macOS 26과 Ubuntu 24.04는 완료 결과를 보존한다. 해당 계열의 후속 변경은 macOS 27과 Ubuntu 26.04 WSL2에서 필요한 범위로 검증한다.
6. 단일 heavy job과 기존 lock을 지키고 w06 자동점검은 PAUSED로 유지한다. 새 장치 실기가 배정되면 현재 inventory와 해당 시점의 장치 소유권을 확인한다. 자료 복구 및 안전한 실기 절차는 00_Docs/MAC_HANDOFF.md에 있다.
7. 정확한 소스 및 문서 커밋별 CI와 실기 결과를 대조한 뒤 HOST-W08과 M33-W07 마감을 판단한다. 공개 tag, Release, asset, stable index, main 통합은 별도 사용자 승인 사항이다.
