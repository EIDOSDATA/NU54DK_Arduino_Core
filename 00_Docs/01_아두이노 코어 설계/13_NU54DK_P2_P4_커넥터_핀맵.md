| 근거 | 보드 소유자가 수기로 확정한 P2/P4 배열 |

## 1. 적용 원칙

이 문서는 NU54DK 실기 시험에서 사용하는 **커넥터 번호와 net의 대응 관계**를 고정한다.
2026-09-05 보드 소유자가 회로도를 직접 확인해 수기로 제공한 배열이며, HIL 결선표를 만들거나
검토할 때 화면상 net label의 위치를 다시 추정하지 않고 이 표를 우선 사용한다.

- `P2`, `P4`는 커넥터 명칭이며 `P0`, `P1`, `P2` GPIO port와 혼동하지 않는다.
- 표의 핀 번호는 커넥터에 인쇄되거나 회로도 심벌에 표시된 물리 번호다.
- GPIO net은 자리수를 명확히 하기 위해 `P1.07`, `P2.04`처럼 두 자리로 표기한다.
- `P1.07`과 firmware 표기 `P1.7`은 같은 GPIO net이지만 커넥터 핀 번호 `P2-7`을 뜻하지 않는다.
- 회로도 문자 기준선이나 인접한 행의 위치만 보고 핀 번호를 한 칸 이동해 해석하지 않는다.
- 이 표를 변경하려면 보드 소유자의 재확인과 HIL 카탈로그 검사를 함께 갱신한다.

기계 판독 단일 원본은
[`nu54dk_connector_pinmap.json`](<../../tests/hil/nu54dk/nu54dk_connector_pinmap.json>)이다.
이 문서와 JSON의 값이 다르면 임의로 선택하지 말고 작업을 중단한 뒤 보드 소유자에게 확인한다.

## 4. HIL 사용 규칙

1. 결선표는 커넥터 명칭, 물리 핀 번호와 GPIO net을 항상 함께 적는다.
2. fixture 실행 전 `v04_fixtures.json`의 모든 endpoint가 기계 판독 핀맵과 일치하는지 Host
   검사를 통과시킨다.
3. `SWDCLK`, `SWDIO`, 전원, reset net을 일반 UART/SPI/TWI/GPIO fixture 신호로 사용하지 않는다.
4. 전원 net의 연결 여부는 핀 번호만으로 결정하지 않고 해당 fixture의 별도 안전 조건을 따른다.
5. 회로도와 이 기준표 사이에 차이가 의심되면 flash나 전원 연결을 진행하지 않는다.
