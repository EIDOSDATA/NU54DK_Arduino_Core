승인을 자동으로 뜻하지 않는다.

## 1. 현재 고정할 사실

- [x] Fixture 101~103 UART, 201~203 SPI, 301 TWI의 승인 route 단독 기능 HIL을 완료했다.
- [x] Fixture 301 원시 JSON/JSONL과 SHA-256, exact image·board identity를 50번 기록에 연결했다.
- [x] Host·문서·inventory·package gate와 DUT/peer 증분 target build를 통과했다.
- [x] 이 문서 정비가 반영된 최종 commit과 원격 `main`을 R00 기준선으로 고정한다.
- [ ] R00에서 공개 API·CLI·artifact·저장 형식·HIL 계약과 기준 측정값을 작성한다.

현재 보드에는 Fixture 301의 SDA·SCL·GND 점퍼가 남아 있다. 소프트웨어 R00~R03에는 결선이
필요하지 않다. Fixture 401을 시작할 때 두 USB 전원을 끄고 기존 점퍼를 제거한 뒤 별도 연결표와
새 confirmation을 사용한다.

## 2. `v0.4.0` 기능 검증 전에 수행할 안정화

- [ ] **R00 — 기준선과 characterization 계약**
  - 시작 조건: 이 문서 정비 commit이 원격 `main`과 일치한다.
  - 작업: Core/board/NCS/toolchain, 공개 API·symbol, builder/package 외부 계약, 대표 ELF·RAM/flash,
    기존 Host/target/HIL 증거와 NOT RUN을 기록한다.
  - 완료: 다음 수정의 전후 차이를 같은 입력으로 비교할 수 있고 금지 변경과 영향 회귀가 명시된다.

- [ ] **R01 — CMake source 소속 정리**
  - 작업: SPIM/SPIS/TWIM/TWIS source를 명시적인 `nucode_arduino_core` target에 한 번만 등록한다.
  - 금지: Kconfig 재설계, SDK·board 변경, public API 또는 Fabric 파일 이동을 섞지 않는다.
  - 완료: 선택/비선택·단독·허용 조합의 resolved config, target membership, 실제 link와 package gate가
    통과한다.

- [ ] **R02 — Serial 전송 완료·timeout·동시 호출 정확성**
  - 작업: stale completion, operation generation, event 소비자, timeout과 DMA buffer 반환, 같은 handle의
    submit/cancel/deactivate 계약을 고정하고 필요한 최소 수정과 실패 회귀를 추가한다.
  - 완료: Host/fault-injection과 target build를 통과하고, runtime payload 영향에 따라 Fixture
    201~203/301의 필요한 부분 또는 전체를 새 exact image로 재검증한다.

- [ ] **R03 — Analog/Stream ISR·stop 동기화**
  - 작업: ISR/thread writer·reader, 진단 snapshot, overflow, stop generation과 lock 대기 경계를 먼저
    기록하고 파일 이동 없이 정확성만 수정한다.
  - 완료: stale stop·overflow·timeout 뒤 callback·반복 start/stop·다른 block 진행을 검증하고 T12에
    사용할 새 exact image를 고정한다.

R01~R03에서 runtime byte가 바뀌면 과거 exact HIL은 역사 증거로 보존하되 새 source의 PASS로
복사하지 않는다. 영향 분석에 따라 필요한 T11 회귀를 마친 뒤 T12 Fixture 401로 이동한다.

## 3. `v0.4.0` RC 전에 완료할 정확성 작업

- [ ] **R04 — LittleFS `File` 공유 slot retain/release**
  - 서로 다른 handle의 copy/assignment/move/close, 마지막 close, stale slot과 실제 thread 교차를
    검증한다. 저장 format·partition과 기존 API는 유지한다.
- [ ] **R05 — 제품 identity 원본 정리**

    manifest schema 수명주기는 분리한다.
- [ ] **T12 — M25 단독 기능 HIL**
  - Fixture 401부터 analog·PWM·event·PDM·I2S·QDEC 합성 신호를 실행한다.
- [ ] **T13~T15 — 동시성·복구·soak와 지원 범위 확정**
