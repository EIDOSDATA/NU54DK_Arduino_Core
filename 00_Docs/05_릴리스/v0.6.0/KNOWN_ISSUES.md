# v0.6.0의 제한과 알려진 문제

## 사용하는 환경에 따라 남는 제한

| 범위 | 현재 판정 |
| --- | --- |
| Ubuntu native 사용자 장치 | `NOT_RUN`. Ubuntu 24.04와 26.04의 사용자 실기는 WSL2에서 수행했습니다. [지원표](SUPPORT_MATRIX.md) |
| Apple/Google 서비스, 외부 제품, 외장 장치 | 실제 제품 상호운용은 사용자 후속 `NOT_RUN`입니다. scripted peer를 사용한 검사의 범위는 각 예제에 기록합니다. |
| Bluetooth Direction Finding, RF, 오디오 | 제품 SDC의 IQ 수신과 AoD는 미지원입니다. 외장 결선, 정밀 음질, 거리 및 각도 보정에는 별도 검증이 필요합니다. |
| 실험적 프로필과 템플릿 | 예제별 opt-in, 자격 증명, 연결과 상대 장치 조건을 확인하세요. [설정 안내](MIGRATION.md) |
| W06 판정 | 실제 PASS 46건, 사용자 명시 수락 3건(#29, #40, #44)입니다. #29 원인 분석은 유예했습니다. [310번 기록](<../../04_검증 기록/310_M33_W06_사용자_수락_마감_완료.md>), [311번 기록](<../../04_검증 기록/311_M33_W06_명시_수락_정정과_HOST_W04_착수.md>) |

## 재현할 때 참고할 실패 기록

| 증상과 입력 | 후속 결과 |
| --- | --- |
| C10 macOS에서 프로세스 그룹 정리 실패 | C11에서 새 소프트웨어 검증을 통과했습니다. 첫 실패 순간에 남아 있던 프로세스의 정확한 상태는 미확정입니다. [331번 기록](<../../04_검증 기록/331_HOST_W07_C11_macOS_26_27_호환성.md>) |
| C11 macOS 26에서 USB 재연결 뒤 첫 UART 응답 시간 초과 | 기본 설정의 실패를 보존했습니다. 명시적 줄 동기화로 물리 재연결을 다시 시험해 통과했습니다. 첫 실패를 유발한 바이트는 미확정입니다. [336번 기록](<../../04_검증 기록/336_HOST_W07_C11_macOS_26_실기_검증과_재연결.md>) |
| C11 macOS 27의 첫 USB 재연결 관찰 시간 초과 | 첫 시도에서는 분리를 감지하지 못했습니다. 사용자가 준비한 뒤 새 관찰에서 분리와 복원을 기록하고 UART 응답 6/6을 확인했습니다. [337번 기록](<../../04_검증 기록/337_HOST_W07_C11_macOS_27_실기_검증과_마감.md>) |
| C11 macOS 27 IDE Upload에서 `No module named 'yaml'` | probe 선택 전에 실행기가 중단됐습니다. C12에서 고정 SDK Python을 사용해 일반 Upload와 LED 동작을 확인했습니다. [설치본 확인 방법](TROUBLESHOOTING.md), [338번 기록](<../../04_검증 기록/338_HOST_W07_macOS_27_Arduino_IDE_Upload_교정.md>) |
